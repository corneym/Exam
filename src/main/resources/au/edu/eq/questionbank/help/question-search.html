Searching and correcting Questions

Open Search

Choose Questions → Search... to search stored Questions and inspect their metadata, classification and preview.

Search scope

Search Questions uses the application's current Working Subject. Change the Working Subject in the main application before opening Search if you need to search a different Subject.

Current syllabus searches Questions according to their applicability within the Working Subject's current syllabus. Use the Unit, Topic, Subtopic and Descriptor controls to narrow the search.

All Questions searches all stored Questions belonging to the Working Subject, including Questions classified against historical curriculum. It does not search Questions belonging to other Subjects.

Classification

The Selected Question Classification section shows the stored classification for the selected Question.

If classification correction is required, select the replacement curriculum location and choose Save.

Changing the stored classification is different from changing Revision Output applicability.

Revision Output applicability

A Question may be applicable to one or more current curriculum locations through confirmed curriculum mappings.

Use Include or Exclude to control whether a particular applicable placement is used in Revision Output.

This changes Revision Output behaviour only. It does not replace the Question's stored classification.

Question preview

The preview shows the stored Question content for the selected search result. Questions containing multiple content parts are displayed in their stored order.

Corpus Dashboard

Choose Questions → Corpus Dashboard... to review the current Working Subject as an Exam, booklet and Question work queue.

The Dashboard shows declared Exam state separately from calculated findings, reports booklet and Question completeness, and provides filters for outstanding Question work.
