Capturing Questions and Answers

Question capture modes

The Question pane supports capturing new Questions and completing outstanding work for previously imported or incomplete Questions.

Opening an Exam booklet does not automatically begin Question capture. Use Start New Question Capture to activate Classification and the Question controls for a new Question.

After a new Question is saved, new-Question capture remains active so the next Question can be captured directly. Editing or correcting an existing Question returns the workspace to its inactive state when that work is finished.

Complete Imported Question appears only when the current Working Subject contains imported or incomplete Questions requiring Question content, replacement source capture or Shared Context resolution. Selecting it exposes the Question selector for that outstanding work.

When no relevant imported/incomplete Questions remain, both the action and its Question selector are removed from the normal capture workspace.

Capture from a PDF

  1. Select the required Question area in the active Exam PDF.
  2. Choose Add Region.
  3. Repeat for additional regions if the Question contains multiple content parts.
  4. Use the content list controls to reorder or remove accepted parts when necessary.
  5. Complete the required Question details and classification.
  6. Choose Save Question.

A selected PDF area is not part of the Question until it has been accepted with Add Region. Clicking elsewhere in the PDF abandons an unaccepted selection; there is no separate discard-selection action.

Accepted content parts are removed individually from the content list. There is no global Clear Content action.

Capture from the clipboard

Use Add From Clipboard to add image content copied to the system clipboard. This supports image capture from tools such as Windows Snipping Tool.

Add From Clipboard is available only while the clipboard contains image content. Clipboard text, files and other non-image content are ignored. Returning to Exam Question Bank after taking a snip refreshes the action automatically.

  1. Copy or snip the required Question content.
  2. Return to Exam Question Bank.
  3. Choose Add From Clipboard.
  4. Confirm the image appears in the Question content list.
  5. Add further PDF regions or clipboard images if required.
  6. Save the Question normally.

Clipboard images are stored as Question content. They do not require the original source image to remain available after the Question has been saved.

Mixed Question content

A Question can contain more than one content part. PDF regions and clipboard images may be combined and are displayed in their stored order.

Use Up, Down and Remove to correct the order before saving.

Shared Context

Shared Context is source material used by more than one Question. Capture it separately from Question-specific content when the same source material applies to multiple Questions or Question parts.

Multipart Question codes such as 21a, 21b and 21c share the source Question 21.

When the first captured part establishes that Shared Context is present, later parts automatically reuse the same stored Shared Context. The application does not ask again for each part.

If the first part establishes that there is no Shared Context, that decision is also reused by later parts.

Shared Context capture uses a single source page. It is not intended for multi-page source material.

When a Question uses Shared Context, the Accepted Question content area shows the Shared Context first, followed by the Question-specific content parts. The Shared Context preview is for reference and is not counted as another Question content part.

Capture an Answer

The Answer pane operates on Questions from the active Question booklet. The Answer or marking PDF assigned to that booklet is the authoritative Answer source.

For a written-response Question, capture one or more regions from the assigned Answer or marking PDF and then choose Save Answer.

For a multiple-choice Question, the stored A, B, C or D choice remains the authoritative Answer.

If the assigned Answer booklet has been marked Contains answer explanations in Exam / Assets, optional explanation regions may also be captured from that marking PDF. These regions supplement the stored A-D choice; they are not required for the MCQ to have a complete Answer.

Retrofit MCQ explanations

  1. Open Exam / Assets and select the required Exam.
  2. Confirm that the Answer booklet is marked Contains answer explanations.
  3. Select the Question booklet whose MCQs are being processed.
  4. Choose Use Selected Booklet for Capture.
  5. In the Answer pane, choose Capture MCQ Explanations.
  6. Select an answered MCQ from the active booklet.
  7. Select the required explanation area in the marking PDF and choose Add Region.
  8. Choose Update Answer.

After a successful update, that MCQ is removed from the current retrofit list and the next candidate is opened automatically. Cancelling an edit leaves that MCQ in the list.

MCQ explanation retrofit is restricted to the active Question booklet. The Answer-booklet flag means that the source document contains explanation material; it does not mean that every MCQ must have an explanation region.
