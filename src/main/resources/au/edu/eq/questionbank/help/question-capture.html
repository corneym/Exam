Capturing Questions and Answers

Question capture modes

The Question pane supports capturing new Questions and completing content for previously imported Questions.

Use Capture New Questions when creating new Question records. Use Capture Imported Questions when adding content to Questions whose metadata already exists.

Capture from a PDF

  1. Open the source PDF in the workspace.
  2. Select the required Question area in the PDF.
  3. Choose Add Region.
  4. Repeat for additional regions if the Question contains multiple content parts.
  5. Use the content list controls to reorder or remove parts when necessary.
  6. Complete the required Question details and classification.
  7. Choose Save Question.

A selected PDF area is not part of the Question until it has been accepted with Add Region.

Capture from the clipboard

Use Paste Image to add image content copied to the system clipboard. This supports image capture from tools such as Windows Snipping Tool.

  1. Copy or snip the required Question content.
  2. Return to Exam Question Bank.
  3. Choose Paste Image.
  4. Confirm the image appears in the Question content list.
  5. Add further PDF regions or clipboard images if required.
  6. Save the Question normally.

Clipboard images are stored as Question content. They do not require the original source image to remain available after the Question has been saved.

Mixed Question content

A Question can contain more than one content part. PDF regions and clipboard images may be combined and are displayed in their stored order.

Use Up, Down and Remove to correct the order before saving.

Shared Context

Shared Context is source material used by more than one Question. Capture it separately from the Question-specific content when the source material applies to following Questions.

Shared Context capture uses a single source page. It is not intended for multi-page source material.

Capture an Answer

The Answer pane operates on a selected Question.

  1. Select the Question whose Answer is being captured.
  2. If the Answer is sourced from a PDF, choose the required Answer PDF.
  3. Select and accept the required Answer region or regions.
  4. For response types that use a stored choice rather than an image region, select the required choice.
  5. Choose Save Answer.
