Exam setup and assets

Open Exam / Assets

Exam / Assets is the authoritative workspace for Exam structure, Question booklets, Answer booklets and booklet-to-Answer assignments.

Normally enter this workspace from Manage Exam / Assets on the Corpus Dashboard.

Create an Exam

Use Add Exam on the Corpus Dashboard when the Working Subject has curriculum available.

Record Provider, Year, Assessment, Expected Question booklets and Expected Answer booklets. These expected asset counts are used by the Corpus Dashboard when deciding whether the Exam structure is complete.

Save the Exam before adding its source booklets.

Question booklets

Use Add Question Booklet to select and register a Question PDF.

For each Question booklet record:

  • its Name;
  • its Type: MCQ, Written Response or Both; and
  • the number of Expected Questions when known.

Expected Questions means the expected number of top-level source Questions in that booklet. It is separate from the Exam-level expected number of Question booklets.

A Question booklet may also be assigned one of the Exam's Answer booklets through its Answer field.

Answer booklets

Use Add Answer Booklet to register an Answer or marking PDF for the Exam.

If the source includes explanatory material for multiple-choice answers, select Contains answer explanations.

This flag creates a completion requirement. Every eligible answered MCQ in a Question booklet assigned to that Answer booklet must have an explanation region before the Exam can be marked COMPLETE.

The flag describes the Answer booklet, not the stored A-D Answer. The A-D choice remains the authoritative multiple-choice Answer.

Activate a booklet for capture

Select the radio button for a persisted Question booklet and choose Use Selected Booklet for Capture when you want that booklet to become the active generic Capture context.

Dashboard task actions can also open capture directly for a specific booklet or Question without requiring this manual activation step.

Correct or delete assets

Use the Exam, Question-booklet and Answer-booklet controls to correct persisted metadata, assignments or source assets.

Structural changes, including adding, deleting or reconfiguring booklets, require an ACTIVE Exam. If the Exam is COMPLETE, return to the Corpus Dashboard and choose Mark Active first.

Return to the Dashboard

When Exam / Assets was opened from the Dashboard, Return to Corpus Dashboard returns to the operational home and refreshes its persisted status.

Finish or cancel any staged Exam or asset edit before returning.
