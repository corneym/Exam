Revision output

Revision HTML

Choose Export → Revision HTML... to generate a static HTML revision resource for the current Working Subject.

The Working Subject is inherited from the Corpus Dashboard and cannot be changed in the export dialog. Select the Units to include, the grouping mode and the destination parent directory.

The generated resource includes only Questions that are applicable to the Working Subject's current curriculum and are not explicitly excluded from the relevant Revision Output placement.

Revision SCORM

Choose Export → Revision SCORM... to produce the SCORM form of the revision resource for the current Working Subject.

The Working Subject is inherited from the Corpus Dashboard and cannot be changed in the export dialog. Unit selection and grouping choices correspond to the Revision HTML workflow, but the result is packaged for SCORM delivery.

Grouping

The selected grouping mode determines how Questions are organised within the generated curriculum hierarchy. It does not change the stored classification of the Questions.

Before exporting

The Working Subject must have exactly one current syllabus version before Revision HTML or SCORM export can begin.

Questions requiring missing content, unresolved metadata or other corpus corrections may prevent or reduce usable revision output.

Use the Corpus Dashboard to review outstanding Exam, booklet or Question work before export.
