Corpus Dashboard

Application home

The Corpus Dashboard is the main operational home for Exam Question Bank. It reports the state of the current Working Subject and provides the entry points for Exam setup, capture and corpus correction.

Changing the Working Subject refreshes the Dashboard to show only Exams, booklets and Questions belonging to that Subject.

Curriculum

The Curriculum section reports mapping-review status for the Working Subject. Use + to add curriculum or Map Curriculum to review mappings.

An Exam cannot be added for a Subject until that Subject has curriculum available.

Exam and booklet hierarchy

The Exams table can be filtered by Provider, Year and declared Exam state. Selecting an Exam shows its Question booklets beside it.

The Question Booklets table reports source availability, expected Question counts, captured Question counts, classification gaps and MCQ explanation coverage where applicable.

Use Manage Exam / Assets for structural Exam work. Use Inspect Questions beside the selected Exam to open Question Search narrowed to that Exam. Select a Question booklet and use its Inspect Questions action to narrow Search to that booklet.

The booklet-level capture actions remain separate from inspection. Use them when capture or correction work belongs to a particular Question booklet.

Outstanding Question work

The summary buttons show the main outstanding work dimensions for the current Dashboard scope, including missing Question content, missing Answers, unknown response type, unresolved Shared Context and missing MCQ explanations.

Selecting a summary button narrows the Exam, booklet and Question views to the relevant work.

The Question Work table identifies the source Exam and booklet as well as the specific problem. Select a Question and use the action beneath the table to complete that work.

For missing MCQ explanations, the selected-Question action becomes Capture Explanation.

Capture from the Dashboard

Use Capture Questions for Question-side work in the selected booklet and Capture Answers for Answer work.

When a booklet has required MCQ explanation work, Capture MCQ Explanations opens that booklet's outstanding explanation queue.

Dashboard-launched capture provides Return to Corpus Dashboard. Returning refreshes the Dashboard from persistence so completed work and counts are immediately updated.

Mark Complete and Mark Active

Exam ACTIVE or COMPLETE is an explicit lifecycle state. It is shown separately from calculated corpus findings.

Mark Complete becomes available only when the Exam is ready for completion. Readiness requires:

  • expected Question-booklet and Answer-booklet counts are recorded and match the available assets;
  • every Question booklet has its Question PDF;
  • every Question booklet has an Expected Questions value matching its encountered top-level Question count;
  • every Question is classified to Descriptor level;
  • there is no outstanding Question content, Answer, response-type or Shared Context work; and
  • every required MCQ explanation has been captured for Answer booklets declared as containing explanations.

A COMPLETE Exam remains available for review and completion of existing persisted work, but structural Exam and asset changes are locked. Choose Mark Active before changing Exam structure.

Legacy Question import

Use Import Legacy on the Dashboard to import legacy Question metadata for the Working Subject.

If required Exam or Question-booklet structure is missing, the workflow uses Exam / Assets to resolve that structure before importing. It does not maintain a separate legacy Exam-creation workflow.
