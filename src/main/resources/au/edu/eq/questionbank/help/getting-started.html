Getting started

Start from the Corpus Dashboard

Exam Question Bank opens on the Corpus Dashboard. The Dashboard is the normal starting point for Exam setup, Question and Answer capture, corpus correction and Exam lifecycle work.

Select the required Working Subject. The same Subject is used throughout Dashboard, Search, curriculum and capture workflows.

If the Subject has no curriculum, add curriculum before creating its first Exam.

Typical workflow

  1. Select the Working Subject.
  2. Add or confirm the Subject's curriculum.
  3. Add an Exam or select an existing Exam on the Dashboard.
  4. Use Exam / Assets to register Question and Answer booklets and their expected counts.
  5. Use the Dashboard work indicators to capture or correct outstanding Questions and Answers.
  6. Resolve any required MCQ explanations.
  7. When all required work is complete, choose Mark Complete.

Open a PDF directly

Use File → Open → PDF... when you need to inspect a PDF independently of an Exam workflow.

Use File → Close PDF when that viewer PDF is no longer required.
