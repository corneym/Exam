Getting started

Main workspace

The main application window combines Question and Answer capture controls with the PDF workspace.

The current Subject and curriculum selection determine the curriculum context used by capture and other workflows.

Open an Exam for capture

  1. Choose Exam → Open Exam for Capture....
  2. Select or import the required Exam material.
  3. Confirm that the correct Subject and Exam are active.
  4. Use the Question capture pane to begin capturing content.

Open a PDF directly

Use File → Open → PDF... when you need to open a PDF in the workspace independently of the Exam capture workflow.

Use File → Close PDF when the current viewer PDF is no longer required.
