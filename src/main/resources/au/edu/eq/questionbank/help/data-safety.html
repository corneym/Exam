Backup, restore and data safety

Backup

Choose File → Backup Now... to create a manual backup of application data.

Backups protect the Question bank and related managed application data. Keep important backups somewhere independent of the active application data directory.

Restore

Choose File → Restore Backup... to restore an application backup.

Restore replaces active application data with the contents of the selected backup. Read the confirmation information carefully before proceeding.

Schema migration

The application manages database schema upgrades when opening data from supported earlier versions. Do not manually edit migration files or the application database.

Application exit

Use File → Exit or close the main application window normally so the application can complete its shutdown and backup workflow.
