-----------------------------------------------------------------------
SPRINT 10 — ACTIVE DEFECT 1: visible PDF selection clears but pending selection remains

Reproduction:
1. Select a valid Question/Answer region in the PDF.
2. Click elsewhere in the PDF without creating another valid region.
3. The visible rectangle disappears.
4. The capture workflow still reports/retains the old pending selection.

Required result:
Visible and logical pending-selection state must clear together and selection
controls must become non-actionable.

-----------------------------------------------------------------------
SPRINT 10 — ACTIVE DEFECT 2: curriculum hierarchy ComboBox state can be stale/out of sync

Observed behaviours:
- Entering a complete curriculum code can populate Subtopic and Descriptor while
  Topic is visibly blank.
- After entering a complete code, replacing it with only the Unit number can
  select/redisplay the previous Topic.
- The problem can occur with no PDF region selected, so it is not solely a PDF
  focus/selection issue.

Required result:
Visible Unit/Topic/Subtopic/Descriptor values and CurriculumSelectionModel must
always represent the same resolved path. Shortening to a Unit must clear all
finer visible/model selections.
